## 🎲 Механика

- 2–4 игрока, ~45 минут, 7+ лет
- Покупай товары за **2$**, продавай в нужном городе за **5$**
- Торговый порт скупает всё по **3$**
- Первый, кто набрал **30$** — раунд доигрывается, побеждает богатейший
- Стартовый капитал: **6$** каждому
